# `packages/tools/llm` — chat-model seam

A narrow, vendor-agnostic seam for programmatic model calls from inside the
platform. Callers depend on the `ChatModel` protocol — never on a specific
vendor — so providers are swappable by config.

## Pieces

| File | What it is |
| --- | --- |
| `client.py` | The `ChatModel` protocol, the shared `ModelError`, and `OpenRouterClient`. |
| `nvidia.py` | `NvidiaClient` — NVIDIA NIM (OpenAI-compatible) with chat, reasoning, streaming, embeddings, and a model registry. |
| `registry.py` | `build_chat_model(provider)` — the **connector** any agent/task uses to get a configured model by name. |

## The protocol

```python
class ChatModel(Protocol):
    def complete(self, system: str, user: str, *, temperature: float = 0.0) -> str: ...
```

Both `OpenRouterClient` and `NvidiaClient` satisfy it, so anything that accepts a
`ChatModel` (e.g. the discovery analyst's `LLMSignalProvider`) works with either.

## Getting a model — the connector

Don't import a vendor client at the call site. Ask the registry:

```python
from packages.tools.llm import build_chat_model

model = build_chat_model("nvidia")            # NVIDIA NIM, default chat model
model = build_chat_model("nvidia:reasoning")  # NVIDIA reasoning model
model = build_chat_model()                    # honours $CHAT_MODEL_PROVIDER, else openrouter

text = model.complete("You are terse.", "Say hi.")
```

Set `CHAT_MODEL_PROVIDER` in `.env` to change the default everywhere without code
edits. Providers: `openrouter`, `nvidia`, `nvidia:reasoning`.

## NVIDIA — beyond `complete()`

`NvidiaClient` adds richer methods when you need them:

```python
from packages.tools.llm import NvidiaClient, NVIDIA_MODELS, DEFAULT_REASONING_MODEL

nim = NvidiaClient(model=DEFAULT_REASONING_MODEL)

# Reasoning model: get the hidden chain-of-thought + the answer
result = nim.chat(
    [{"role": "user", "content": "9.11 or 9.9 — which is larger?"}],
    enable_thinking=True,
    reasoning_budget=4096,
)
result.reasoning_content   # the model's scratch work (None for non-reasoning models)
result.content             # the final answer
result.usage               # token counts

# Streaming
for piece in nim.chat_stream([{"role": "user", "content": "Write a haiku."}]):
    print(piece, end="")

# Embeddings (asymmetric retrieval)
vectors = nim.embed(["how do I reset my password?"], input_type="query")

# Vision: pass OpenAI-style content blocks to a NVIDIA_MODELS["vision"] model
nim_v = NvidiaClient(model=NVIDIA_MODELS["vision"]["llama-3.2-90b-vision"])
```

Get a key at <https://build.nvidia.com> and set `NVIDIA_API_KEY` in `.env`.

## Setup

```
NVIDIA_API_KEY=nvapi-...
# optional:
CHAT_MODEL_PROVIDER=nvidia
```

## Extending to image / audio

NVIDIA's image (SDXL, Sana, Cosmos) and speech (Riva, Parakeet) models live on
sibling endpoints under the same host and key. Add a method (e.g.
`generate_image`) that builds the payload and calls `NvidiaClient.request_json`
(or `_post` for binary replies) — auth, error typing, and decoding already live
there. See the `EXTENSION POINTS` note at the bottom of `nvidia.py`, and mirror
`packages/tools/content_tools` (Gemini image gen) for persisting generated bytes
as artifacts.
```
