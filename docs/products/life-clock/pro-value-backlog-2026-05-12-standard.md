## 1. State summary

The Pro plumbing is in good shape — three-tier paywall is App-Store-safe (annual-first, equal-price prominence, restore in both surfaces, no dark patterns), `EntitlementGatedWritesTests` lock the `.notEntitled` defensive paths, and the 5/10 subscription-lifecycle pass landed clean three-state restore alerts with a swipe-down dismiss indicator. Two of MONETIZATION.md's five "best conversion moments" are wired (post-Life-Clock-reveal via onboarding terminal paywall; locked-detail-tap via History fog + Future slider lock). But **three best moments are completely unused** (first weekly report preview, advanced-HealthKit-metrics request, widget/Lock-Screen surfaces), **WrapUpSheet — a documented best moment — has zero Pro signaling**, **PaywallSheet's main header copy makes generic depth claims** ("Full weekly reports, tailored action plans, and deeper trend breakdowns") that don't enumerate what's actually behind the wall, and **Profile's Subscription section is missing the explicit cancel pointer** the Trust rubric requires (the fineprint mentions iOS Settings, but the user-facing Subscription section has no "Manage subscription / How do I cancel?" affordance — only Restore). One **`trust-gap`** (no in-app cancel pointer from Profile/Settings) and one **`value-claim-unjustified`** (paywall header copy is generic, doesn't enumerate Pro features) are escalated to submission-blocker tier — both surface here before the prompt list.

**Submission-blocker findings up front (must be resolved before App Store submission):**

1. **`trust-gap` — Profile Subscription section has no in-app cancel pointer.** Rubric Trust criterion ["Clear cancel path. The user can find 'how do I cancel?' within 3 taps from any Pro surface."](pro-value-rule.md#trust) is violated for active Pro users. [ProfileView.swift:146–170](../../../products/life-clock-ios/Sources/Features/Profile/ProfileView.swift) renders "Pro · Active" with only a Restore button below — no Manage Subscription affordance. The PaywallSheet fineprint mentions "Subscriptions auto-renew until cancelled in iOS Settings → [your name] → Subscriptions" but the active Pro user never reopens the paywall. App Store reviewers flag this. → **Prompt 1**.
2. **`value-claim-unjustified` — PaywallSheet header copy is generic.** [PaywallSheet.swift:112–119](../../../products/life-clock-ios/Sources/Features/Paywall/PaywallSheet.swift) reads: "Full weekly reports, tailored action plans, and deeper trend breakdowns. Your free experience keeps working either way." The MONETIZATION.md Pro feature list (full time ledger / advanced HealthKit metrics / weekly reports / historical archive / correction power / custom quests / deeper trend breakdown / widgets/Lock-Screen / export-delete) has 9 entries; the header surfaces 3 generic ones, and the only deep-dive section is `whatIfSimulatorTeaser` (Future tab specific). Justification fails the rubric's ["Is the justification concrete?"](pro-value-rule.md#justification) test for everything that isn't What-If. → **Prompt 2**.

**Pro-value-readiness: red.** Reason: two unresolved submission-blocker prompts above + three unused best-conversion moments. Restoration to **yellow** needs Prompts 1 + 2 done; to **green** needs the upsell-moment + value-claim + perceived-depth ratchets in Prompts 3, 4, and 5.
