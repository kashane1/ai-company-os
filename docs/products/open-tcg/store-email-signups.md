# Store drop emails: signups and setup

Which independent stores email about drops, which ones you're signed up to (`ksakhakorn@gmail.com`), what's left for you to do, and how store mail reaches the radar. Plan: [store drop emails](../../plans/2026-10-24-open-tcg-store-drop-emails.md). Survey data: [`2026-10-24-store-email-signup-survey.json`](research/2026-10-24-store-email-signup-survey.json).

## Your to-do list

1. **Confirm the double opt-in emails** in your inbox from: Thirdspace TCG, Wulf Gaming, Common Lands. Level Up Games (Mailchimp) may also send one.
2. **Sign up at the 52 stores below.** Shopify's built-in signup form shows a CAPTCHA to automated browsers, so these need you. Each takes about 20 seconds: open the link, scroll to the footer email box, enter your address and tick the CAPTCHA. The drop-specific stores and the 14 first-pass stores come first.
3. **Add the Gmail forwarding filter** (below), so the radar sees store mail and can check the store and notify you within a minute.
4. **Optional: join Discord servers.** Some stores announce drops there first. The radar doesn't read Discord.

## Gmail forwarding filter

The radar reads the project inbox (`jimsimons01102000@gmail.com`) every 30 seconds, read-only. To let it see store mail sent to your address, set up forwarding in **ksakhakorn@gmail.com**:

1. Gmail → Settings → **Forwarding and POP/IMAP** → **Add a forwarding address** → `jimsimons01102000@gmail.com`. Gmail sends a confirmation code to that address. Ask Claude to read it from the project inbox, then enter it.
2. In the Gmail search box, paste the query below → **Create filter** → **Forward it to** `jimsimons01102000@gmail.com`. Also tick **Never send it to Spam**, and apply a label such as "TCG drops" if you like.

```
from:(wulfgaming.com OR common-lands.com OR flipsidegaming.com OR kollectkorner.com OR loosepacks.com OR poke-collect.com OR stonebrookcollectibles.com OR tcg-stadium.com OR beckettcastletcg.com OR forgeandfiregaming.com OR levelupgamesatl.com OR tcgmoonblast.com OR tcgslayer.io OR thirdspacetcg.com)
```

This query covers the stores you're subscribed to. Some stores send from a different domain (a Gmail address, or Shopify Email). As those emails arrive, `radar store-mail-filter` adds their senders, so re-run it and update the filter after you add new signups or notice store mail that isn't being forwarded.
