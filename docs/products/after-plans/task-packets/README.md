# After Plans Task Packets

These packets translate the product artifact chain into lane-aligned next steps without collapsing planning, iOS implementation, App Store work, and GTM into one blob.

## Packet Sequence

1. supervisor decomposition and sequencing
2. iOS MVP shell and core-loop planning
3. trust and safety plus moderation primitives planning
4. App Store positioning and metadata asset preparation
5. GTM and launch asset preparation

## Lane Rules

- `supervisor` owns sequencing, policy escalation, and cross-lane coordination
- `ios` owns app-shell implementation planning and later code work
- `appstore` owns metadata and release-prep artifacts only
- GTM remains founder-supervised documentation work, not a new autonomous lane

## Resume Use

Open the packet that matches the next recommended phase in `../PHASE_STATUS.md`, then use the `Resume Point` section to continue without re-deriving the whole product.
