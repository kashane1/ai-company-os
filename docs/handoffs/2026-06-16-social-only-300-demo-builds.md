## Per-build SOP (one prospect at a time)
1. `python3 scripts/agency/gather_place.py --place-id <PID> --max-photos 10` → place-details.json + photos.
2. Read EVERY candidate photo at FULL RES individually (memory: montage thumbs mislead; catch AI-stock/"Imagined with AI" watermarks, wrong-business photos, faces, license plates).
3. Write `source/content-brief.md` (verified facts each w/ source; paraphrased testimonials no names; lead-with strengths NOT contradicted by complaints; real CTAs; guardrails) + `source/03-design-direction.md` (distinctness mandate naming sibling palettes; palette hex; type; photo plan; section flow; craft pass).
4. Stage photos with PIL (center-crop AR, max ~1300px, q86-87; blur plates; face-free crops or flag owner photos "confirm before publish").
5. Dispatch a general-purpose build subagent (strict inputs = the 2 source files + a craft reference build; self-contained single index.html; Maps QUERY LINK not iframe; no invented data).
6. Verify gate (Bash): `git checkout -- .claude/ && git clean -fdq .claude/`; ghost grep; img/iframe counts; per-category integrity scans; body em-dash + price-leak scan; `git status --porcelain .claude/` clean; `screenshot_demo.py --label v2`.
7. Eyeball the screenshot. Then record in this doc (bump count, advance row, 1-line done-entry) + advance.

- Reject AI-generated/stock photos + photos that belong to a different (same-named) business.
